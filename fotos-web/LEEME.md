# Fotos web (respaldo)

Fotos de artistas que llegaron por el chat y no se pudieron subir a la carpeta "Fotos web" de Drive.
En la planilla (pestaña Web Line-up, columna "Foto (link de Drive)") se usa su enlace directo:
https://raw.githubusercontent.com/lookatflowers/lookatflowers.github.io/main/fotos-web/<archivo>

Si luego se sube la foto a Drive, basta con cambiar el link en la planilla y borrar el archivo de aquí.
